# Curso Profético: Daniel y Apocalipsis

Plataforma Web Progresiva (PWA) de interpretación profética desarrollada con un enfoque exegético riguroso, basada en los principios de la *Sola Scriptura*, el historicismo consecuente, la teología del santuario y la integración armoniosa de los escritos del Espíritu de Profecía.

## 🌟 Características Principales
* **Interfaz PWA Moderna:** Diseño responsivo y optimizado con Tailwind CSS y componentes interactivos para dispositivos móviles y de escritorio.
* **Sistema de Lecciones Estructurado:** Módulos interactivos que abarcan desde los principios hermenéuticos fundamentales hasta el análisis cronológico y profético de Daniel y Apocalipsis.
* **Esquemas Gráficos y Visuales:** Infografías integradas y líneas de tiempo exegéticas (como la progresión continua de Daniel 2 y el diagrama de las siete iglesias).
* **Herramientas de Estudio Personalizado:** Selector de lecciones, barra de progreso global dinámica y un área de apuntes de notas por lección.
* **Evaluación Interactiva:** Preguntas de comprobación de aprendizaje con retroalimentación inmediata al finalizar cada lección.

---

## 🛠️ Estructura del Proyecto
* `index.html`: Archivo principal que contiene toda la estructura de la aplicación, el motor de navegación de las lecciones, los estilos de Tailwind y la base de datos de contenidos en JavaScript (`COURSE_DATA`).

---

## 🚀 Instalación y Uso Local

1. Clona o descarga este repositorio en tu equipo local.
2. Abre la carpeta del proyecto en tu editor de código preferido (como **VS Code**).
3. Abre el archivo `index.html` directamente en tu navegador web favorito (Google Chrome, Firefox, Edge, etc.) o utilízalo mediante una extensión de servidor local como *Live Server*.

## 💡 Metodología Teológica
* **Sola Scriptura:** Utilización de la Escritura como su propio intérprete mediante paralelos canónicos línea por línea.
* **Historicismo:** Interpretación de las profecías apocalípticas como una cadena cronológica ininterrumpida desde la antigüedad hasta la Segunda Venida de Cristo.
* **Teología del Santuario:** Marco interpretativo centrado en el ministerio de Cristo como Sumo Sacerdote y el contexto del juicio celestial.
